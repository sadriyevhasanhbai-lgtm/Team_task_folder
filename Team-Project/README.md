# Team Project — Organize a Messy Folder 📁

An automated Python utility script designed to clean up chaotic and disorganized directories by sorting files into well-structured category subfolders (e.g., `Images`, `Documents`, `Archives`, `Code`, etc.).

---

## 🚀 Features
* **Smart Categorization:** Automatically groups files based on their extensions using a modular logic structure.
* **Safe Operations:** Checks for existing files in destination folders to prevent accidental overwrites (`skip and explain`).
* **Robust Validation:** Safely handles empty directories, incorrect paths, and skips nested subfolders to ensure clean execution.

---

## ⚙️ Requirements
* Python 3.x
* Standard libraries only (`os`, `shutil`) — no external installations required.

---

## 🛠️ How to Run
To run the program, open your terminal or command prompt inside the project folder and execute the following command:

```bash
# python main.py
